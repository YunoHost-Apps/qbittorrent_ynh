## What changed

`{{ url }}/api` used to be reachable without logging in. It is now admin-only, like the rest of the web interface.

Apps on this server (Sonarr, Radarr…) reach qBittorrent directly on `http://127.0.0.1:{{ port }}`, without a password. Clients on another machine use `{{ url }}/ext`, username `admin`, with a password checked by qBittorrent.

{% if password %}qBittorrent had no password of its own, or was still on the `adminadmin` default, so one was generated:

**{{ password }}**

Update your external clients. You can change it from *Tools > Options > Web UI*, and find it again in this app's admin documentation.{% else %}Your qBittorrent password is unchanged — use it in your external clients, pointed at `/ext`.{% endif %}

If your instance was open to the internet, *Tools > Options > Downloads > Run external program* and your torrent list are worth a quick look.
